# U52 人生场合致辞：用一个真实小故事写出两分钟退休致辞

本练习面向普通用户，示范如何把零散回忆组织成一篇简短、自然、不编造经历的退休致辞。所有姓名、地点、机构、数字与事件均为虚构素材。练习者不需要使用真实同事或真实单位信息。

## 文件地图

- `materials/`：活动卡当前版与旧版、重复件、回忆卡、缺项便签和错误 AI 草稿。
- `tutorial/退休致辞起草实操教程.md`：五步教程，从确认场合、选故事、搭结构到计时复核。
- `reference/参考致辞与陷阱核验.md`：版本陷阱答案、故事来源核对、参考稿和验收清单。
- `templates/人生场合致辞提示词模板.md`：可替换对象、关系、时长、故事和边界的复用模板。
- `results/两分钟退休致辞参考稿.md`：本例最终草稿。

## 示例背景

虚构发言人周宁是松风社区阅读室的前同事；致辞对象是许澜老师。练习活动为退休茶话会，目标时长约两分钟。唯一确认的个人故事是周宁刚加入时曾把 17 本书放错位置，许澜陪她核对书架编号并一起重新归位。其他履历、年龄、家庭故事和退休原因都没有提供，不可自行补充。

## 使用边界

这套材料是写作练习，不代表任何真实人物或机构。致辞由发言人本人确认和修改；AI 不能替人证明故事真实性，也不能替代发言人最终发表。
